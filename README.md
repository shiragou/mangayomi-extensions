# Mangayomi 中文 Novel 扩展

## 添加扩展

点击下方按钮，将 Novel 扩展仓库添加到 Mangayomi：

<a href="https://intradeus.github.io/http-protocol-redirector?r=mangayomi://add-repo?repo_name=shiragou-mangayomi-extensions%26repo_url=https://github.com/shiragou/mangayomi-extensions%26novel_url=https://raw.githubusercontent.com/shiragou/mangayomi-extensions/main/novel_index.json"><img alt="添加 Novel 扩展仓库" src="https://raw.githubusercontent.com/m2k3a/mangayomi-extensions/main/images/add-novel-repository.png" height="35"></a>

也可以在 Mangayomi 中进入 **更多 → 设置 → 浏览 → Novel 扩展仓库**，手动添加：

```text
https://raw.githubusercontent.com/shiragou/mangayomi-extensions/main/novel_index.json
```

添加仓库后，在 Novel 扩展列表中安装所需扩展即可。
